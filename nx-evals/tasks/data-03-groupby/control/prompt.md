Define a function `group_by_mod3(xs)` that takes a list of non-negative numbers and returns a dict with keys `"0"`, `"1"`, and `"2"` (string keys), where each key maps to the list of input numbers whose remainder when divided by 3 equals that key, in their original order. Keys with no matching numbers must still be present and map to an empty list. An empty input returns all three keys mapping to empty lists.
